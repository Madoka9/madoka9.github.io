[[基本#几何阶段]]

Model

模型变换(model tranformation)：将模型空间转换到世界空间

View( Camera )

摄像机变换(view tranformation)：将世界空间转换到观察（摄像机）空间

Projection

投影变换(projection tranformation)：将观察空间转换到裁剪空间

Orthographic（正交） Projection

定义了一个Cube

    • 看向 -z 方向， 即 f < n ;
  • OpenGl是左手系，
  • 投影之后会有拉伸（都变换到了[-1, 1]），但是会在之后的 ##视口变换# 重新映射

Perspective（透视） Projection

  • 定义了一个 Frustum


    透视投影的核心：用“远平面”和“近平面”框住物体，先把“远平面”向“近平面“挤压，然后做一次正交投影。

即透视投影分为两步：

  • 将透视投影转化为正交投影
  • 将正交投影转换到正则立方体

因此先求透视投影到正交投影的变换矩阵：

Step1. “挤压”， 将Frustum挤压成Cuboid

  • 规定，
    • 近平面不发生任何改变；
    • 深度不发生改变
    • 中心点不发生改变

Viewport Transform

视口变换
将处于标准平面映射到屏幕分辨率范围之内，即[-1,1]^2->[0,width]*[0,height], 其中 width和height指屏幕分辨率大小 视锥表示看起来像顶部切割后平行于底部的金字塔的实体形状。
这是透视摄像机可以看到和 渲染的区域的形状。

  • 长宽比 Aspect
