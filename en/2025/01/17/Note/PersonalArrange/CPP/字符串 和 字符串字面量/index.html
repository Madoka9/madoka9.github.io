二、字面量

字符串后面有一个额外的字符–空终止字符“\0” 或 0

MV


在字符串中间添加终止字符，如果使用strlen(name)获取字符串长度，只会计算到终止符之前。

  • 字符串字面量永远保存在内存的只读区域内

const char* name1 = “Name1”;

const wchar_t* name2 = L”Name2”;

const char16_t* name3 = u”Name3”;

const char32_t* name4 = U”Nmae4”;
